# Code of Conduct

## Our standard

Be respectful, constructive, and focused on the technical work. Harassment,
discrimination, threats, doxxing, and publication of another person's private
data are not acceptable.

This project handles metadata derived from local development sessions. Never
post real session files, prompt content, account identifiers, or unsanitized
project paths when asking for help.

## Enforcement

Maintainers may edit or remove comments, issues, pull requests, or other
contributions that violate this standard, and may temporarily or permanently
restrict participation.

Report conduct concerns privately to a maintainer using a contact method listed
on that maintainer's GitHub profile. Report security vulnerabilities through
GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).
